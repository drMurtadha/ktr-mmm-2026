# Pembentangan KTR MMM 2026/2027

Laman pembentangan Aluan Menjalankan Tugas Pengetua Kolej Tun Razak, Universiti Teknologi Malaysia. Mengandungi 27 slaid versi terkini, fail PowerPoint dan PDF.

## Pembentangan

- Tekan **Mulakan pembentangan** untuk paparan skrin penuh.
- Anak panah kiri/kanan, Page Up/Page Down atau Space menukar slaid.
- **F** membuka/menutup skrin penuh, **B** merehatkan skrin, **Esc** kembali.
- Home/End pergi ke slaid pertama/terakhir.
- Pada telefon, leret kiri/kanan untuk menukar slaid.
- URL `?present=1#slide-1` membuka paparan pembentangan terus.
- URL `#slide-6` membuka slaid tertentu.

Fail slaid menggunakan imej daripada PDF akhir untuk mengekalkan penampilan PowerPoint. Teks slaid juga tersedia untuk aksesibiliti. Tiada perkhidmatan pihak ketiga atau penjejak digunakan.

## GitHub Pages

Terbitkan daripada branch `main`, folder `/ (root)`. Fail `.nojekyll` membolehkan penerbitan statik terus.

## Kemas kini

Gantikan PDF/PPTX dalam `downloads/`, eksport slaid kepada JPEG 1920px dalam `assets/slides/`, dan kemas kini `slides.json` apabila kandungan berubah. Pastikan jumlah serta urutan slaid sepadan.
